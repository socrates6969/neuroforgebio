# Neural interface stills

Frames of `/interface/?record=1&captions=0` (2560x1440), rendered by `tools/playground/render-stills.mjs`
from the built site, one set per theme. t = 0.5 s overview, 6 s array close-up, 11 s neurons firing, 21 s decoder,
cursor and simulated arm.

Required caption and credit wherever these are used: "Illustrative anatomy and device; not a specific product.
Firing replayed from open data: O'Doherty, J. (2024) MC_RTT, DANDI 000129, https://doi.org/10.48324/dandi.000129/0.241017.1444,
CC BY 4.0. Research demo; not a medical device; no hardware is controlled." The credit line is burnt into each frame.
