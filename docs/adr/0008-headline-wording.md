# ADR 0008: One heading set for both themes

- Status: **Accepted**
- Date: 2026-09-26
- Deciders: owner (Marius Carlsson) at GATE B
- Source: `architecture/DECISIONS.md` D8, `BRIEF.md` "GATE B decision". Company name: NeuroForge Bio.

## Decision

Both themes use the same headings and copy. Emphasis is marked once in content and painted differently by each theme.

## Consequences

No per-theme voice overrides in v1. If ever allowed: at most 10 override strings per theme, lint-checked.
