## Known gaps

- Nothing CI-only has run: the first owner-approved `workflow_dispatch` of `ci.yml` may surface cdxgen/pip-audit flag
  or output-format drift; the gate fails closed (empty or unparsable audit output exits 2).
- pip-audit reports no severity, so every fixable Python finding blocks until fixed or covered by VEX.
- **Gap (SEC-087):** `.npz` is not on the list, because two research result files are tracked (`research/somatosensory/code/results/p1_boot_R.npz`, `p2_example.npz`). Add `.npz` once the research results move out of this repo (agreed with nfb-security, 2026-09-26).
- hw-guard's `command` rule will also hit ordinary code such as Rust `std::process::Command` in a `build.rs`
  under `core/`; by design there is no allow marker, so such code needs the owner's decision (or lives outside the
  scanned directories). **Proposal (nfb-security, 2026-09-26), not applied:** keep the full-text match in `proto/` and `openapi/`, but narrow it in `core/`, `bindings/` and `sdk/` to exported API identifiers (`pub fn`, `extern "C"`, pyfunction/pyclass names). This narrows a §G control, so it needs the owner's written OK when the first real Rust code lands.
- **Open (SEC-083, M2-REVIEW MinIO decision):** `bitnamilegacy/minio` is a frozen, unmaintained image, approved for CI tests with synthetic data only and marked `unmaintained` in the SBOM. It must be **replaced before M5 closes** (candidates, not evaluated: another S3-compatible test server, or moto's S3 mode). Owner: the storage decision (queen / owner). Production uses the cloud provider's S3 (D4, Object Lock for the audit bucket), never MinIO: see `docs/security/object-storage.md`; `tests/security/test_minio_ci_only.py` fails if MinIO appears in any non-CI compose/infra file.
- **Open (M2-REVIEW F6, SEC-052):** API-key pepper rotation accepts one pepper version; verify against `{current, previous}` for a grace period when rotation is built.
- **Open (M2-REVIEW F7, SEC-041):** the stream sanity amplitude limits are 1 V placeholders; per-modality limits (with the source of each) must be set **before any real-data tenant**.
- SEC-017 checks run when a chunk arrives: an idle open stream is not closed by the server (it writes nothing); a server-side idle timeout is future work.
- Required status checks need a `pull_request` trigger, which the owner has not enabled (see branch-protection.md).
