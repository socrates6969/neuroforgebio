| ID | Type | Prereg text | What the code does, and why |
|---|---|---|---|
| D1 | INTERPRETATION | N2 §1 buffer: "Training windows whose end lies within 10 s of the start of any test file are dropped. In practice this removes the last 10 s of the last training file (inter-file gaps are ~7 s)." | The literal rule is implemented: a training window [a, e) (absolute subject time) is dropped if e > t_start(test) - 10 and a < t_end(test) + 10 (strict inequality). | D2 | INTERPRETATION | N2 §2 tau rule: inner leave-one-training-file-out CV. | The inner-CV models are fitted on the same buffer-kept windows as the final model; OOF scores are produced for ALL windows of the held-out training file (a complete hypothesis is needed for event scoring). No buffer is applied between inner folds (the prereg specifies none). tau is scanned upward from 0.05 and the scan stops at the first tau with FA <= 12/24 h; this gives exactly "the smallest tau" and saves time. |
| D3 | INTERPRETATION | N2 §2 classifier: "Either sklearn ... or scipy L-BFGS-B". | scipy.optimize.minimize(method="L-BFGS-B", gtol=1e-6, maxiter=1000) on the stated summed objective, float64, zero init, analytic gradient; the default ftol of L-BFGS-B is left unchanged. sklearn is NOT installed. | D4 | INTERPRETATION | N2 §3 "each test file is scored separately", FA denominator. | timescoring EventScoring on each test file's 1-Hz masks; TP, FP, N_ref and H summed per subject. Sample scores use timescoring SampleScoring at fs = 1, also summed. |
| D5 | INTERPRETATION | Harness §3 latency. | Latency uses the merged/split reference events (same as the scorer) and the first RAW 1-Hz hypothesis second inside [onset-30, offset+60); if only merge filler overlaps, the first merged-hypothesis second is used. |
| D6 | INTERPRETATION | N2 §8 RNG streams: default_rng(SeedSequence(20261001, spawn_key=(k,))). | Each stream k is created once per process and consumed sequentially in a fixed documented order: subjects chb01, chb03, chb10; replicates 0..R-1; files chronological. | D7 | INTERPRETATION | N1 (b)2 chance null: "hypothesis mask circularly shifted by 1,000 random offsets". | Offsets are uniform integers in [0, T) per replicate, per test file (np.roll of the 1-Hz mask; events wrap around the file end). | D9 | INTERPRETATION | N1 (b) NC1 "i.i.d. permutation of the training window labels ... full N2 pipeline (including the tau rule)". | The permutation is over all windows of all training files of the subject jointly (same number of positives).
