# NeuroForge Bio

B2B neural-data infrastructure for brain-computer-interface teams: hardware-agnostic ingest (BIDS, LSL, EDF/BDF, NWB, XDF), reproducible pipelines with provenance, a Neuro-AI model registry, SDKs (Python, C++, Unity/Unreal), and neural-data privacy governance.

**Founder and owner:** Marius Carlsson

Status: pre-product. This repository holds the company's planning and research work.

| Folder | Contents |
|---|---|
| `BRIEF.md` | Master plan, rules and owner decisions |
| `market/` | Market research, regulation, sizing, pricing, name screening |
| `design/` | Six website design options (options 1 "clinical" and 3 "cosmos" chosen) and competitor teardown |
| `architecture/` | Enterprise blueprint and build guide (awaiting owner approval) |
| `research/somatosensory/` | Computational research on bidirectional closed-loop somatosensory feedback (theoretical/simulation only; any clinical application requires IRB/FDA oversight) |

Nothing here is a medical device or a medical claim.
