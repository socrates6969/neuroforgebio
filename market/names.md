# Company Name Screen: NeuroForge (owner's choice), 2026-09-26

**Method:** live HTTP fetches (curl, the GitHub API via an authenticated `gh`, PyPI JSON, the npm registry and npm search), all run on 2026-09-26. WebSearch was exhausted, so any company that does not appear on these domains, registries or GitHub was **not** covered.

**Status meanings:**
- "no response" = no HTTP answer on the day. It does **not** mean the domain is unregistered or buyable.
- "parked (/lander)" = a JS redirect to `/lander`, which is typical of registrar parking.

We checked no prices and contacted no one.

**Trademark databases: not checked.** USPTO tmsearch, EUIPO eSearch, WIPO Global Brand Database and Patentstyret (search.patentstyret.no) all return only a JavaScript app shell (HTTP 200, no results) to a plain fetch. The USPTO backend API refused a direct query (405 MethodNotAllowed). **A registered NeuroForge mark therefore cannot be ruled out in the US, the EU or Norway.**

### Companies and products using the name (found)
1. **NeuroForge GmbH & Co. KG (Germany):** AI/Big-Data custom software. It is the most serious clash: an EU company in the same broad software/AI class, operating under the identical name.
2. **NeuroForge (Australia, neuroforge.io):** an AI research company with named products.
3. **NeuroForge (neuro-forge.com):** agentic AI, RL and cyber-defense lab.
4. A PyPI ML framework, and open-source BCI/EEG projects under the same name.

No NeuroForge in medical devices or clinical neurotech was found in this pass. That sector was not searchable without WebSearch or trademark databases.

### Verdict: **risky / crowded**
- At least three live AI businesses already trade as NeuroForge, including one EU GmbH.
- The .com is parked, the .ai is on a marketplace, the .io is in use, and the PyPI name and the "NeuroForge Labs" GitHub orgs are taken.
- "Neuro" + "Forge" is a common coinage pattern, so the mark is likely weak and crowded.
- Adopting the plain name without an attorney clearance search is **not** recommended, especially for EU sales (Neuroforge GmbH).
