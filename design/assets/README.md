# NeuroForge (working name) — hero graphics

Self-contained, iframe-ready HTML files. Each one fills its container, caps DPR at 2, pauses when the tab is hidden or the graphic is off-screen, and shows a static frame under `prefers-reduced-motion`. All data is synthetic. Only external request: three.js from jsdelivr, used by asset 3.

- `asset-1-clinical.html` — Clinical precision (light): top-down 10–20 montage (21 electrodes), with calm traces flowing into 19 stacked channel lines. Canvas 2D. `<iframe src="assets/asset-1-clinical.html" title="10-20 EEG montage with flowing channel traces" style="border:0;width:100%;height:560px"></iframe>`
- `asset-2-terminal.html` — Dark dev-infra terminal: oscilloscope-style stream, with noisy raw traces becoming clean past a `clean()` divider and an LSL status line. Canvas 2D. `<iframe src="assets/asset-2-terminal.html" title="Streaming EEG cleaned in real time, terminal view" style="border:0;width:100%;height:560px"></iframe>`
- `asset-3-cosmos.html` — Immersive 3D neural cosmos: brain-shaped point cloud of about 12k points (hemispheres, sulci, cerebellum, stem), additive glow, firing arcs and pointer parallax. three.js 0.160 (ES module from cdn.jsdelivr.net) plus a custom point shader. `<iframe src="assets/asset-3-cosmos.html" title="Glowing 3D brain point cloud" style="border:0;width:100%;height:640px"></iframe>`
- `asset-4-editorial.html` — Editorial science plate: procedural engraving-style lateral brain (labyrinth gyri, hatching, Latin lobe labels), red sensor-to-model pathway with numbered callouts 1–4, and a Fig. 1 caption. SVG plus CSS stroke-draw that plays once on load. `<iframe src="assets/asset-4-editorial.html" title="Fig. 1 — Signal pathway from sensor to model" style="border:0;width:100%;aspect-ratio:16/10"></iframe>`
- `asset-5-dashboard.html` — Data-viz dashboard: interpolated scalp topomap, band-power bars, 8-channel trace panel, and a p50 ingest-latency sparkline tagged "DEMO DATA". Canvas 2D. `<iframe src="assets/asset-5-dashboard.html" title="Live analytics dashboard, demo data" style="border:0;width:100%;height:600px"></iframe>`
- `asset-6-warm.html` — Warm human/biotech: organic network of 36 soma nodes with bezier dendrites, breathing motion, warm glow, and cascading pulses. Canvas 2D. `<iframe src="assets/asset-6-warm.html" title="Warm organic neuron network" style="border:0;width:100%;height:560px"></iframe>`
