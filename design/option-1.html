01 — Platform

One pipeline, from electrode to model.

Four stages, each versioned and reproducible, with provenance recorded at every step.

  1. 01 / Ingest

    Hardware-agnostic ingest

    Connectors for EEG, ECoG, and microelectrode arrays, with low-latency time-series storage.

    • BIDS
    • Lab Streaming Layer
    • EDF/BDF · NWB · XDF
  2. 02 / Clean

    Automated neuro-cleaning

    Versioned, reproducible pipelines with provenance for every transform.

    • Filtering
    • ICA · artifact rejection
    • Re-reference · normalize
  3. 03 / Neuro-AI

    Model marketplace

    Motor-intent decoding, cognitive-state estimation, or bring your own model. Benchmarks published with methods.

    • motor-intent
    • cognitive-state
    • BYO model
  4. 04 / SDKs

    Stream in, predictions out

    Native SDKs for analysis, embedded devices, and real-time 3D applications.

    • Python
    • C++
    • Unity / Unreal

Python SDK

Four lines from stream to prediction.

Connect a device over LSL, apply a cleaning pipeline, and run a marketplace model on the result.

import neuroforge as nf
stream = nf.connect("lsl://headset-01")
clean  = stream.pipeline("ica-default").run()
intent = nf.models.get("motor-intent/v1").predict(clean)
# Illustrative API — subject to change
