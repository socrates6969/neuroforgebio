## Tenant keys (LAUNCH REQUIREMENT)

The platform's envelope encryption (NR-H1) wraps each subject's data key under its tenant's KMS key,
addressed by alias `<NF_KMS_KEY_ALIAS_PREFIX>nf/tenant/<tenant_id>` (default `alias/nf/tenant/<uuid>`).
Tenants are rows created at runtime in the platform database, but the platform **cannot create KMS
keys** (its task role has no `kms:CreateKey`/`CreateAlias`, on purpose). So:

1. Create the tenant row; note its `tenant.id` (lower-case UUID).
2. Add the id to `tenant_ids` (tfvars) and have the owner `tofu apply`. This creates the key and the
   alias (`module.kms`; output `tenant_kek_aliases`).
3. Only then accept uploads/streams for the tenant. Before step 2 its first write fails (KMS
   `NotFoundException` -> `KmsKeyUnavailable`); no data is written unencrypted.

Tenant keys have `prevent_destroy`: removing an id from `tenant_ids` fails the plan, because
destroying the key crypto-shreds all of that tenant's data. Offboarding (SEC-034) is a deliberate
owner change. The task role gets `GenerateDataKey`/`Decrypt`/`DescribeKey` only on keys whose alias
matches `alias/nf/tenant/*`, and no `ScheduleKeyDeletion`.

The platform env block sets `NF_ENVIRONMENT`, `NF_S3_BUCKET_PREFIX`, `NF_KMS_BACKEND=aws` and
`NF_KMS_KEY_ALIAS_PREFIX`. A prod env must set `NF_ENVIRONMENT = "prod"`: the platform then refuses to
start on anything but S3 + AWS KMS. Only envs/dev exists today; no prod or staging env is written yet.

No secrets in state: the DB password is generated by RDS (`manage_master_user_password`) and only its
Secrets Manager ARN is an output; containers receive secrets by ARN at runtime. CI also greps `infra/` for
literal `password = "..."`/`secret = "..."` assignments.

CI-only (`tofu` is not installed on the dev PC), workflow `.github/workflows/infra.yml` (manual dispatch):

```sh
tofu fmt -check -recursive infra
tofu -chdir=infra/envs/dev init -backend=false
tofu -chdir=infra/envs/dev validate
tofu -chdir=infra/envs/dev test      # plan against mock_provider "aws"
tofu -chdir=infra/modules/phi-guard init -backend=false && tofu -chdir=infra/modules/phi-guard test
```
